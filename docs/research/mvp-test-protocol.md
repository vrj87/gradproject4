# MVP test protocol (Part 6)

**Method:** Moderated 20–25 min session, remote or same machine. Return to **≥ 3 people from S2** (the Phase 4 segment — not mixed Photos users).  
**MVP:** http://localhost:3000/demo/task/task-goa-cafe (or Playground → Test this).  
**Record in:** the Test view (`http://localhost:3000/test`) or `docs/research/mvp-test-notes/t01.md`. Form replies and “I liked it” comments do not count (A-T03).

Open with: “This is a prototype library, not your Google Photos. We will try to find one photo from a fragment of memory. I will not hint unless you are stuck — and then it will not count as success.”

If they think this is their real account, stop and restate (X-04). Do not collect Google credentials.

---

## 0:00–3:00 · Qualify (must still be S2)

Same bar as Phase 3. Do not count toward n ≥ 3 if they fail:

- Google Photos is the primary library for ≥ 12 months
- Library large enough that scrolling is not the default find method
- The photo they could not find was a trip / place vibe (café, lights, boat), not a screenshot, medicine pack, or known-item keyword that already worked

If Phase 3 notes exist, use **that respondent’s retrieval task**. If the original photo cannot be used, pick the closest seed task and label it **representative** (X-01). Form respondents r01–r03 map to task-goa-cafe, task-goa-trip, and task-concert-lights.

---

## 3:00–10:00 · Baseline (required, A-T05)

1. Open **Search** (keyword). Do not open Remember yet.
2. Ask them to type whatever they would type in Google Photos for this photo.
3. Score: **success** (they open the target without help) / **miss** / **abandoned**.
4. If they already succeed on keywords, record it. The MVP may still be tried, but it is not “the unlock” for them (X-02).

---

## 10:00–20:00 · Remember (the job)

1. Open **Remember** with the same task (`/demo/task/…` or Playground → Test this).
2. They speak or type fragments. You may remind them the composer wants vibe / object / episode — not date first.
3. At most three product questions. Moderator hints (“try café”) = **not unassisted** (X-03).
4. They may open a photo, tap More like this / Not this trip / That’s the one.
5. Score: **success** / **miss** / **abandoned**. Time-to-open-target if they succeed — or label **not timed** on an instrumented seed run (X-01).

Capture: cues they used; which question helped; which annoyed; whether they thought this was Search.

---

## 20:00–25:00 · One change

Ask: “If we change one thing before the next person, what should it be?”  
You must write **one next-iteration change** or the session fails A-T04.

---

## What counts toward n ≥ 3

| Counts | Does not count |
|--------|----------------|
| S2, unassisted, baseline attempted, MVP attempted, next-iteration written | Preference (“nice UI”), hinted success, non-S2, keyword-only, form-only |

If all three fail the task, change Remember before claiming success on slide 9 (X-05).

**Notes filename:** `t01.md` … `t03.md` (anonymized). No fellow or respondent names.
