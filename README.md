# Google Photos — Core Experience

NextLeap PM fellowship project. The job is helping people retrieve a photo they still picture but cannot precisely describe — not a better search box.

**Live production prototype:** [Open Photos](https://remember-photos.netlify.app/?view=photos). Remember is the hypothesis. Search is the keyword baseline. This is a deployed prototype, not the Google Photos product or its production telemetry.

For local development, run `npm run dev` from this folder (Photos storefront on http://localhost:3000).
